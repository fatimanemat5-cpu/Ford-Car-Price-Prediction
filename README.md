# Ford Car Price Prediction

This project predicts the price of used Ford cars using Machine Learning.

## Files
* 'Ford.csv' - Dataset of used Ford Cars.
* 'Predict_oldcar.ipynb' - Python code for data analysis and price prediction.

## Tools Used
   * Python
   * Pandas,Numpy
   * Matplotlib,Seaborn
   * Scikit-Learn

 ## Model
    * Linear Regression
